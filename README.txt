EXECUTIVE COMMAND CENTER — OPTION B STARTER

Files:
- index.html: dashboard
- style.css: responsive styling
- app.js: system selection and launch links
- manifest.json: installable PWA metadata
- sw.js: basic same-origin shell caching

IMPORTANT:
This is a starter dashboard, not a live integration platform yet. System tiles open the original services. Cross-service search, in-dashboard email/calendar actions, and Clio record search require provider-authorized API integrations and secure OAuth configuration. Do not put API secrets, OAuth client secrets, passwords, tokens, or private client data in this public repository.

Selected system names are stored in this browser's localStorage. No business records are stored or sent to a custom database by this starter app.

To deploy:
1. Extract this ZIP.
2. Upload the files inside the folder to the root of your GitHub Pages repository.
3. Commit to the main branch.
4. Wait for Pages to publish, then reload the site.
